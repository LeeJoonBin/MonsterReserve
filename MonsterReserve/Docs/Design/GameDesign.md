## 2. 핵심 게임 루프

플레이어가 계속 반복하는 한 바퀴를 순서대로 적어 보세요. FPS와 RPG가 만나는 지점이 어디인지가 이 게임의 개성이 됩니다.

1. 의뢰를 받음
2. 오픈월드에서 의뢰 대상 몬스터를 찾아 사냥
3. 처치한 위치로 가서 시체를 확인하면 의뢰 완료, 의뢰비 획득
4. 모은 돈으로 거점에서 총기 구매
5. 의뢰 대상이든 아니든 몬스터를 처치하면 경험치를 얻고, 레벨업하면 스킬 획득 (예: 탐지 거리 증가)
6. 더 좋은 총기와 스킬로 다시 1번으로

생각해 볼 질문

- 플레이어는 왜 오픈월드를 돌아다니나요? (퀘스트, 사냥, 탐험, 수집 등)
- 싸워서 얻은 것은 무엇이고, 그것으로 무엇이 강해지나요?
- 저격이 가장 빛나는 순간은 어떤 상황인가요?

## 3. 사격 시스템

무기 종류에 따라 맞았는지 판정하는 방식을 나눕니다.

| 무기 구분 | 판정 방식 | 특징 |
| --- | --- | --- |
| 즉시 판정 무기 (권총, 샷건, 라이플) | 즉시 판정 (히트스캔) | 쏘는 순간 맞았는지 결정. 탄도 없음 |
| 탄도 무기 (저격총, 런처) | 탄도 계산 (투사체) | 총알이 실제로 날아가며 맞았는지 결정 |

**탄도 계산에 넣을 요소** (중력 낙차와 비행 시간만 넣고, 바람과 공기 저항은 추후 추가)

| 요소 | 플레이어가 느끼는 것 | 넣을까요? |
| --- | --- | --- |
| 중력에 의한 낙차 | 멀수록 조준점을 위로 올려야 함 | 넣음 (투사체 계산으로 자연스럽게 발생) |
| 비행 시간 | 움직이는 적은 앞을 보고 쏴야 함 | 넣음 (투사체 계산으로 자연스럽게 발생) |
| 바람 | 옆으로 흘러가는 총알을 보정해야 함 | 넣지 않음 (시간이 남으면 추후 추가) |
| 공기 저항 | 멀수록 총알이 느려지고 더 많이 떨어짐 | 넣지 않음 (별도 계산이 필요해 바람과 함께 추후 추가) |

생각해 볼 질문

- 저격은 어느 거리부터 "멀다"고 느껴져야 하나요? 이 거리가 5번 오픈월드의 크기와도 이어집니다.

### 무기 구매와 레벨업 스킬

처음에는 권총으로 시작합니다. 다른 무기는 레벨업으로 해금되는 것이 아니라, 의뢰를 완료하고 받은 의뢰비로 구매합니다. 의뢰 대상 몬스터를 처치한 뒤 시체를 확인하면 의뢰가 완료되어 의뢰비가 들어옵니다. 몬스터 시체에서 아이템을 얻거나 파는 파밍은 없습니다. 총기 구매는 맵 중앙의 거점에 가서 합니다. 돈은 무기 구매에만, 경험치는 스킬에만 쓰이며, 무기에는 레벨 제한이 없습니다.

| 무기 | 판정 방식 | 얻는 방법 |
| --- | --- | --- |
| 권총 | 즉시 판정 | 시작 무기 |
| 라이플 | 즉시 판정 | 구매 (가격 미정) |
| 샷건 | 즉시 판정 | 구매 (가격 미정) |
| 저격총 | 탄도 계산 | 구매 (가격 미정) |
| 런처 (추가 여부 미정) | 탄도 계산 (저격총의 투사체 코드 재사용) | 구매 (가격 미정) |

**조준**: 모든 총은 마우스 오른쪽 클릭으로 조준하면 화면이 확대됩니다. 저격총은 처음부터 스코프가 달린 상태로 판매되며, 확대 배율이 다른 총보다 큽니다. 총별 배율은 미정입니다.

**레벨업 보상: 스킬**

- theHunter처럼 레벨업하면 스킬을 얻음. 스킬은 아래 세 갈래로 나눔
- 무기 부착물과 무기 공격력 같은 수치 강화는 넣지 않음

| 갈래 | 사용 방식 | 효과 | 세부 스킬과 수치 |
| --- | --- | --- | --- |
| 무기 다루기 | 패시브 | 무기별 재장전 속도, 조준 속도 같은 손놀림 향상 | 미정 |
| 탐지와 추적 | 사용형 | 사용하면 몇 초 동안 대상 몬스터의 위치를 방향으로 표시. 사용 키는 Q | 미정 (표시 시간 미정) |
| 은신 | 패시브 | 맞았을 때 몬스터가 플레이어를 감지할 확률을 낮춰 줌 (기본 100%, 최소 50%) | 미정 |
| 회복 (힐) | 사용형 | 사용하면 체력 회복. 레벨업할 때마다 사용 횟수 증가 또는 회복량 증가로 강화. 다 쓴 횟수는 거점의 회복 지점과 상호작용하면 초기화. 사용 키는 G | 미정 (기본 횟수, 기본 회복량, 증가량) |

**몬스터 감지와 추격 규칙**: 몬스터에게는 감지 거리와 피격 시 감지 거리 두 가지가 있으며, 피격 시 감지 거리가 더 큽니다. 감지한 몬스터는 플레이어를 추격하고, 플레이어와 가까워지면 공격합니다. 거리 값은 미정입니다.

| 플레이어와 몬스터의 거리 | 몬스터의 반응 |
| --- | --- |
| 감지 거리 안 | 쏘지 않아도 100% 감지 → 추격, 가까워지면 공격 |
| 감지 거리 밖 \~ 피격 시 감지 거리 안 | 맞았을 때 (기본 100% − 은신 감소값) 확률로 감지 → 추격, 가까워지면 공격. 은신으로 낮출 수 있는 최솟값은 50% |
| 피격 시 감지 거리 밖 | 맞아도 감지하지 않음 |

**플레이어 체력과 사망**: 플레이어는 체력을 가지며, 몬스터에게 공격받으면 체력이 줄어듭니다. 체력이 0이 되면 바로 사망하고, 사망한 뒤에는 무조건 새로운 게임을 시작합니다 (이전 진행은 이어지지 않음). 체력 수치는 미정입니다. 저장은 저장 버튼을 눌렀을 때, 그리고 사망하지 않은 상태로 게임을 종료할 때 자동으로 합니다. 사망한 뒤 게임을 나갈 때는 저장 데이터를 삭제합니다. 사망 화면에서 강제 종료하면 삭제되지 않아 마지막 저장 시점으로 돌아갈 수 있는데, 이는 재도전으로 허용합니다.

## 4. RPG 요소

RPG 요소는 종류가 많아서 범위가 가장 쉽게 커지는 부분입니다. 포트폴리오에서 꼭 보여 주고 싶은 것만 "지금"에 두세요.

| 요소 | 예시 | 지금 / 추후 / 안 함 |
| --- | --- | --- |
| 캐릭터 성장 | 레벨, 능력치, 스킬 트리 | 지금 (레벨업마다 스킬 획득) |
| 장비 | 무기 교체, 부품 개조, 방어구 | 지금 (돈으로 총기 구매. 부착물은 넣지 않음) |
| 인벤토리 | 아이템 보관, 무게 제한 | 안 함 (파밍이 없어 들고 다닐 아이템이 없음) |
| 퀘스트 | 의뢰 받기, 목표 추적 | 지금 (의뢰 대상 몬스터를 처치하고 시체를 확인하면 의뢰비 지급. 유일한 돈 획득 방법). 거점의 의뢰 게시판에서 받음. 게시판에는 의뢰 5개가 붙어 있고, 동시에 최대 3개까지 수락 가능. 수락한 의뢰서 자리는 비어 있다가 일정 시간이 지나면 새 의뢰가 랜덤으로 채워짐 (시간은 임시값으로 정하고 플레이 후 조정). 시간은 게임을 켜고 있는 동안만 흐르며, 저장할 때 자리별 남은 시간을 함께 저장. 의뢰 내용: 대상 몬스터 1마리 처치, 의뢰비, 대상 몬스터의 주요 서식 방향 (거점 기준, 예: 북동, 남서) |
| NPC와 대화 | 상점, 의뢰인 | 판매 기능 없음. 총기는 맵 중앙의 거점에 가서 구매 |
| 적 | 종류, 행동 방식, 드롭 아이템 | 지금 (몬스터. 처치 후 시체를 확인하면, 의뢰 대상일 때 의뢰 완료. 모든 몬스터는 처치 시 경험치를 주며, 의뢰 대상이 아니면 경험치만 획득. 플레이어를 감지하면 추격하고 가까워지면 공격 (3번 "몬스터 감지와 추격 규칙")) |

- 성장이 저격의 손맛과 어떻게 이어지나요? (예: 성장하면 숨 참기 시간이 늘어난다)

## 5. 오픈월드

"적당한 크기"를 숫자로 바꾸는 섹션입니다. 오픈월드는 크기가 곧 작업량이라, 1인 개발에서는 여기서 범위가 결정됩니다.

| 항목 | 생각해 볼 질문 | 작성란 |
| --- | --- | --- |
| 크기 | 끝에서 끝까지 걸어서 몇 분이면 될까요? | 끝에서 끝까지 걸어서 약 20분 (이동 속도 초속 3\~5m 가정 시 한 변 약 3.6\~6km). 거점은 맵 중앙 |
| 구역 | 성격이 다른 지역이 몇 개 있나요? (예: 숲, 마을, 폐허) | 맵의 특정 위치마다 테마가 다른 구역을 두고, 구역마다 다른 몬스터가 나옴. 테마는 사용 에셋 기준 (서부 개척지, 늪, 묘지, 성/요새 등). 위치는 배치도로 제공, 구역별 몬스터는 미정 |
| 이동 수단 | 걷기와 달리기만 있나요? | 걷기와 달리기만 (탈것과 빠른 이동 없음) |
| 저격 지점 | 멀리까지 내려다볼 수 있는 높은 곳이 있나요? | 정해진 저격 지점은 따로 만들지 않음. 플레이어가 지형을 이용해 원하는 위치에서 저격. 구조물을 배치할 때 구역마다 멀리 내려다볼 수 있는 지형이 있는지 확인 |
| 거점 | 총기를 사는 거점은 몇 개이고, 어디에 두나요? | 맵 중앙에 하나. 총기 구매와 의뢰 수락 장소 |
| 에셋 | 지형과 건물은 어떤 에셋을 쓸 건가요? | POLYGON Western Frontier, Adventure, Knights (Synty), Low Poly Swamp Nature, NecroPOLY Lite (7번 표 참고) |
| 저장 | 월드의 무엇을 저장하나요? (플레이어 위치, 처치한 적, 열어 본 상자 등) | 저장 (플레이어 행동으로 바뀌는 값만): 돈, 구입한 무기, 스킬 (회복 스킬 강화 단계 포함), 레벨과 경험치, 수락한 의뢰 (최대 3개), 의뢰 게시판 5자리 (자리별 의뢰 내용, 빈 자리는 남은 시간), 회복 남은 횟수, 플레이어 위치. 후순위 (지금은 저장하지 않고 이어가기 시 가득 찬 상태로 시작): 현재 체력, 무기별 남은 탄약, 들고 있던 무기. 설정 값 (마우스 감도, 소리 크기)은 사망 시 삭제되지 않도록 게임 저장 파일과 따로 저장. 처치한 몬스터는 10분 뒤 다시 나옴 (임시값, 게임 중에만 시간이 흐름). 몬스터 상태는 저장하지 않고, 게임을 다시 켤 때 모든 몬스터를 새로 배치 |

**배치도**: 거점, 서식지, 저격 지점 등의 위치는 직접 그린 맵 도식으로 따로 제공합니다. Claude는 그 도식을 기준으로 구조물을 배치합니다.

맵 도식을 그릴 때 넣을 것 (Claude Code가 정확하게 배치하기 위한 기준)

- [ ] 격자와 좌표: 맵을 바둑판처럼 나누고 칸마다 번호를 붙인다 (예: "B-3 칸에 서식지")
- [ ] 축척: 한 칸이 몇 미터인지 적는다
- [ ] 방위: 어느 쪽이 북쪽인지 표시한다 (의뢰서의 "거점 기준 북동" 같은 방향이 이 기준으로 계산됨)
- [ ] 범례: 거점, 서식지, 저격 지점, 길 같은 기호가 각각 무엇인지 적는다
- [ ] 서식지 정보: 서식지마다 어떤 몬스터가 사는지 함께 적는다

## 6. 화면과 상태 흐름

Claude가 맡을 UI 작업의 기준입니다. 화면(씬)과 팝업마다 보여 줄 정보와 이동을 적습니다.

| 화면 (씬) | 보여 줄 정보 | 누를 수 있는 것 | 다음 화면 |
| --- | --- | --- | --- |
| 시작 화면 | 게임 제목, 시작 버튼 목록 | 새로운 게임, 이어가기 (저장 데이터가 없으면 회색으로 비활성화), 게임 종료 | 새로운 게임: 처음부터 게임 화면, 이어가기: 저장된 상태로 게임 화면, 게임 종료: 종료. 새로운 게임은 확인 팝업 없이 바로 기존 저장 데이터를 덮어씀 |
