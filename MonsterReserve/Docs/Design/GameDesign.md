## 2. 핵심 게임 루프

플레이어가 계속 반복하는 한 바퀴를 순서대로 적어 보세요. FPS와 RPG가 만나는 지점이 어디인지가 이 게임의 개성이 됩니다.

1. 의뢰를 받음
2. 오픈월드에서 의뢰 대상 몬스터를 찾아 사냥
3. 처치한 위치로 가서 시체를 확인하면 의뢰 완료, 의뢰비 획득
4. 모은 돈으로 거점에서 마법 구매
5. 의뢰 대상이든 아니든 몬스터를 처치하면 경험치를 얻고, 레벨업하면 스킬 획득 (예: 탐지 거리 증가)
6. 더 좋은 마법과 스킬로 다시 1번으로

- 싸워서 얻은 것은 무엇이고, 그것으로 무엇이 강해지나요?

## 3. 마법 사격 시스템

총기 대신 마법을 사용합니다. 매직 미사일 같은 마법 투사체를 발사하고, 그 투사체로 탄도학을 구현합니다. 시작 마법 마력탄은 투사체입니다. 그 밖의 마법 종류와 판정 방식 (투사체 / 즉시 판정)은 미정입니다.

**마력탄 규칙** (10번 결정 기록 2026-11-16, 2026-11-17)

- 왼쪽 클릭 한 번에 한 발. 누르고 있어도 더 나가지 않음
- 마나가 소모량보다 적으면 발사되지 않음 (부족할 때 알림은 미정)
- 아무것도 맞히지 않으면 일정 시간 뒤 사라짐
- 피해는 **탄이 실제로 날아간 거리** (포물선 경로 길이)가 길수록 줄어듦. 감소가 시작되는 거리까지는 기본 피해, 감소가 끝나는 거리부터는 최소 피해
- 맞은 몬스터에게는 탄을 쏜 위치가 전달되고, 몬스터는 그 위치 쪽으로 이동함 (플레이어를 계속 따라가지는 않음)
- 탄속, 마나 소모, 피해, 감소 거리 등 수치는 마력탄 프리팹에서 플레이하며 조정함
- 발사 위치는 카메라 중앙 (화면 조준점). 위아래로 겨누면 탄도 같은 각도로 나감

**탄도 계산에 넣을 요소** (중력 낙차와 비행 시간만 넣고, 바람과 공기 저항은 추후 추가)

| 요소 | 플레이어가 느끼는 것 | 넣을까요? |
| --- | --- | --- |
| 중력에 의한 낙차 | 멀수록 조준점을 위로 올려야 함 | 넣음 (투사체 계산으로 자연스럽게 발생) |
| 비행 시간 | 움직이는 적은 앞을 보고 쏴야 함 | 넣음 (투사체 계산으로 자연스럽게 발생) |
| 바람 | 옆으로 흘러가는 마법 투사체를 보정해야 함 | 넣지 않음 (시간이 남으면 추후 추가) |
| 공기 저항 | 멀수록 마법 투사체가 느려지고 더 많이 떨어짐 | 넣지 않음 (별도 계산이 필요해 바람과 함께 추후 추가) |

생각해 볼 질문

- 저격은 어느 거리부터 "멀다"고 느껴져야 하나요? 이 거리가 5번 오픈월드의 크기와도 이어집니다.

### 마법 구매와 레벨업 스킬

처음에는 마력탄으로 시작합니다. 다른 마법은 레벨업으로 해금되는 것이 아니라, 의뢰를 완료하고 받은 의뢰비로 구매합니다. 의뢰 대상 몬스터를 처치한 뒤 시체를 확인하면 의뢰가 완료되어 의뢰비가 들어옵니다. 몬스터 시체에서 아이템을 얻거나 파는 파밍은 없습니다. 마법 구매는 맵 중앙의 거점에 가서 합니다. 돈은 마법 구매에만, 경험치는 스킬에만 쓰이며, 마법에는 레벨 제한이 없습니다.

| 마법 | 판정 방식 | 얻는 방법 |
| --- | --- | --- |
| 마력탄 | 투사체 | 시작 마법 |
| 그 밖의 마법 (종류 미정) | 미정 | 구매 (가격 미정) |

**마나**: 마법은 마나를 사용합니다. R키를 누르고 있으면 명상하며, 누른 시간만큼 마나가 찹니다. 명상 중에는 이동할 수 없습니다. 최대 마나와 명상 중 초당 회복량은 임시값입니다 (10번 결정 기록 2026-11-15). 마법별 소모량은 마법 프리팹에서 정합니다.

**조준**: 모든 마법은 마우스 오른쪽 클릭으로 조준하면 마법으로 줌인되어 화면이 확대됩니다. 오른쪽 버튼을 누르고 있는 동안 줌인되고, 떼면 원래 화면으로 돌아옵니다. 화면은 한 번에 바뀌지 않고 부드럽게 확대, 축소됩니다. 줌인 중에는 마우스 감도가 낮아집니다. 줌인 정도, 속도, 감도 비율은 플레이하며 조정합니다. 마법별 배율은 미정입니다 (10번 결정 기록 2026-11-17).

**레벨업 보상: 스킬**

- theHunter처럼 레벨업하면 스킬을 얻음. 스킬은 아래 세 갈래로 나눔
- 마법 공격력 같은 수치 강화는 넣지 않음

| 갈래 | 사용 방식 | 효과 | 세부 스킬과 수치 |
| --- | --- | --- | --- |
| 마법 다루기 | 패시브 | 마법 시전 속도, 줌인 속도 향상 | 미정 |
| 탐지와 추적 | 사용형 | 사용하면 몇 초 동안 대상 몬스터의 위치를 방향으로 표시. 사용 키는 Q | 미정 (표시 시간 미정) |
| 은신 | 패시브 | 맞았을 때 몬스터가 플레이어를 감지할 확률을 낮춰 줌 (기본 100%, 최소 50%) | 미정 |
| 회복 (힐) | 사용형 | 사용하면 체력 회복. 레벨업할 때마다 사용 횟수 증가 또는 회복량 증가로 강화. 다 쓴 횟수는 거점의 회복 지점과 상호작용하면 초기화. 사용 키는 G | 미정 (기본 횟수, 기본 회복량, 증가량) |

**몬스터 감지와 추격 규칙**: 몬스터는 감지 범위, 시야각, 가림 여부로 플레이어를 감지합니다. 감지한 몬스터는 평소보다 빠르게 플레이어를 추격하고, 공격 거리 안이면 공격합니다. 수치는 임시값입니다 (결정 기록 참고).

| 상황 | 몬스터의 반응 |
| --- | --- |
| 감지 범위 안 + 시야각 안 + 가려지지 않음 | 확률 없이 감지 → 평소보다 빠르게 추격, 공격 거리 안이면 공격 |
| 위 조건 밖에서 맞음 (범위 밖, 등 뒤, 가려진 곳) | (100% − 은신, 최소 50%) 확률로 감지. 성공하면 맞은 순간의 플레이어 위치로, 실패하면 쏜 위치로 이동 |
| 추격 중 플레이어가 감지 범위를 벗어남 | 마지막으로 본 위치까지 가서 멈춤 |
| 체력이 기준 이하 | 추격하지 않고 플레이어 반대 방향으로 도망, 일정 거리 이상 멀어지면 멈춤. 플레이어가 보여도 도망이 우선 |
| 체력 0 | Death 애니메이션, 더 이상 움직이지 않음 |

**플레이어 체력과 사망**: 플레이어는 체력을 가지며, 몬스터에게 공격받으면 체력이 줄어듭니다. 체력이 0이 되면 바로 사망하고, 사망한 뒤에는 무조건 새로운 게임을 시작합니다 (이전 진행은 이어지지 않음). 체력 수치는 미정입니다. 저장은 저장 버튼을 눌렀을 때, 그리고 사망하지 않은 상태로 게임을 종료할 때 자동으로 합니다. 사망한 뒤 게임을 나갈 때는 저장 데이터를 삭제합니다. 사망 화면에서 강제 종료하면 삭제되지 않아 마지막 저장 시점으로 돌아갈 수 있는데, 이는 재도전으로 허용합니다.

## 4. RPG 요소

RPG 요소는 종류가 많아서 범위가 가장 쉽게 커지는 부분입니다. 포트폴리오에서 꼭 보여 주고 싶은 것만 "지금"에 두세요.

| 요소 | 예시 | 지금 / 추후 / 안 함 |
| --- | --- | --- |
| 캐릭터 성장 | 레벨, 능력치, 스킬 트리 | 지금 (레벨업마다 스킬 획득) |
| 장비 | 무기 교체, 부품 개조, 방어구 | 지금 (돈으로 마법 구매) |
| 인벤토리 | 아이템 보관, 무게 제한 | 안 함 (파밍이 없어 들고 다닐 아이템이 없음) |
| 퀘스트 | 의뢰 받기, 목표 추적 | 지금 (의뢰 대상 몬스터를 처치하고 시체를 확인하면 의뢰비 지급. 유일한 돈 획득 방법). 거점의 의뢰 게시판에서 받음. 게시판에는 의뢰 5개가 붙어 있고, 동시에 최대 3개까지 수락 가능. 수락한 의뢰서 자리는 비어 있다가 일정 시간이 지나면 새 의뢰가 랜덤으로 채워짐 (시간은 임시값으로 정하고 플레이 후 조정). 시간은 게임을 켜고 있는 동안만 흐르며, 저장할 때 자리별 남은 시간을 함께 저장. 의뢰 내용: 대상 몬스터 1마리 처치, 의뢰비, 대상 몬스터의 주요 서식 방향 (거점 기준, 예: 북동, 남서) |
| NPC와 대화 | 상점, 의뢰인 | 판매 기능 없음. 마법은 맵 중앙의 거점에 가서 구매 |
| 적 | 종류, 행동 방식, 드롭 아이템 | 지금 (몬스터. 처치 후 시체를 확인하면, 의뢰 대상일 때 의뢰 완료. 모든 몬스터는 처치 시 경험치를 주며, 의뢰 대상이 아니면 경험치만 획득. 플레이어를 감지하면 추격하고 가까워지면 공격 (3번 "몬스터 감지와 추격 규칙")) |

- 성장이 저격의 손맛과 어떻게 이어지나요? (예: 성장하면 숨 참기 시간이 늘어난다)

## 5. 오픈월드

"적당한 크기"를 숫자로 바꾸는 섹션입니다. 오픈월드는 크기가 곧 작업량이라, 1인 개발에서는 여기서 범위가 결정됩니다.

| 항목 | 생각해 볼 질문 | 작성란 |
| --- | --- | --- |
| 크기 | 끝에서 끝까지 걸어서 몇 분이면 될까요? | 한 변 2.5km (이동 속도 초속 3\~5m 가정 시 끝에서 끝까지 걸어서 약 8\~14분). 3 × 3 격자로 나누며, 중앙 칸은 500m, 바깥 칸은 1000m. 거점은 맵 중앙 |
| 구역 | 성격이 다른 지역이 몇 개 있나요? (예: 숲, 마을, 폐허) | 맵의 특정 위치마다 자연 지형이 다른 구역을 두고, 구역마다 다른 몬스터가 나옴. 구역 목록과 위치는 Dreamscape 에셋 구성 확인 후 결정, 구역별 몬스터는 미정 (지금은 서식지 5곳 모두 Skeleton Warrior, 임시) |
| 이동 수단 | 걷기와 달리기만 있나요? | 걷기와 달리기만 (탈것과 빠른 이동 없음) |
| 저격 지점 | 멀리까지 내려다볼 수 있는 높은 곳이 있나요? | 정해진 저격 지점은 따로 만들지 않음. 플레이어가 지형을 이용해 원하는 위치에서 저격. 구조물을 배치할 때 구역마다 멀리 내려다볼 수 있는 지형이 있는지 확인 |
| 거점 | 마법을 사는 거점은 몇 개이고, 어디에 두나요? | 맵 중앙에 하나. 마법 구매와 의뢰 수락 장소 |
| 에셋 | 지형과 건물은 어떤 에셋을 쓸 건가요? | 맵은 Dreamscape Nature Mountains 하나만 사용 (7번 표 참고). 거점 건물은 사용자가 직접 추가 |
| 저장 | 월드의 무엇을 저장하나요? (플레이어 위치, 처치한 적, 열어 본 상자 등) | 저장 (플레이어 행동으로 바뀌는 값만): 돈, 구입한 마법, 스킬 (회복 스킬 강화 단계 포함), 레벨과 경험치, 수락한 의뢰 (최대 3개), 의뢰 게시판 5자리 (자리별 의뢰 내용, 빈 자리는 남은 시간), 회복 남은 횟수, 플레이어 위치. 후순위 (지금은 저장하지 않고 이어가기 시 가득 찬 상태로 시작): 현재 체력, 현재 마나, 들고 있던 마법. 설정 값 (마우스 감도, 소리 크기)은 사망 시 삭제되지 않도록 게임 저장 파일과 따로 저장. 처치한 몬스터는 10분 뒤 다시 나옴 (임시값, 게임 중에만 시간이 흐름). 몬스터 상태는 저장하지 않고, 게임을 다시 켤 때 모든 몬스터를 새로 배치 |

**배치도**: 거점, 서식지, 저격 지점 등의 위치는 직접 그린 맵 도식으로 따로 제공합니다. Claude는 그 도식을 기준으로 구조물을 배치합니다.

맵 도식을 그릴 때 넣을 것 (Claude Code가 정확하게 배치하기 위한 기준)

- [ ] 격자와 좌표: 맵을 바둑판처럼 나누고 칸마다 번호를 붙인다 (예: "B-3 칸에 서식지")
- [ ] 축척: 한 칸이 몇 미터인지 적는다
- [ ] 방위: 어느 쪽이 북쪽인지 표시한다 (의뢰서의 "거점 기준 북동" 같은 방향이 이 기준으로 계산됨)
- [ ] 범례: 거점, 서식지, 저격 지점, 길 같은 기호가 각각 무엇인지 적는다
- [ ] 서식지 정보: 서식지마다 어떤 몬스터가 사는지 함께 적는다

## 6. 화면과 상태 흐름

Claude가 맡을 UI 작업의 기준입니다. 화면(씬)과 팝업마다 보여 줄 정보와 이동을 적습니다.

| 화면 (씬) | 보여 줄 정보 | 누를 수 있는 것 | 다음 화면 |
| --- | --- | --- | --- |
| 시작 화면 | 게임 제목, 시작 버튼 목록 | 새로운 게임, 이어가기 (저장 데이터가 없으면 회색으로 비활성화), 게임 종료 | 새로운 게임: 처음부터 게임 화면, 이어가기: 저장된 상태로 게임 화면, 게임 종료: 종료. 새로운 게임은 확인 팝업 없이 바로 기존 저장 데이터를 덮어씀 |
| 게임 화면 (1인칭) | 항상 표시: 동서남북 방향 (나침반), 체력, 마나, 조준점, 돈, 회복 남은 횟수 | M: 맵 열기, J: 의뢰 정보 열기, ESC: 일시 정지 메뉴, G: 회복 스킬 사용, Q: 탐지와 추적 스킬 사용, E: 상호작용 | M을 누르면 맵 화면, J를 누르면 의뢰 정보 팝업, ESC를 누르면 일시 정지 메뉴 |
| 맵 화면 | 전체 맵 위에 플레이어 위치와 거점만 표시 (구역, 의뢰 대상은 표시하지 않음). 열려 있는 동안 게임이 멈춤 | M: 맵 닫기 | 닫으면 게임 화면 |
| 의뢰 정보 팝업 | 수락한 의뢰 목록 (최대 3개). 의뢰마다 대상 몬스터, 주요 서식 방향 (거점 기준), 의뢰비 (그 밖의 표시 정보는 미정). 배경은 살짝 투명해서 뒤의 게임 상황이 보임. 열려 있는 동안에도 게임은 멈추지 않음. 팝업이 열리면 마우스 커서가 나타나고, 이동은 되지만 시점 회전과 사격은 안 됨 | J: 닫기 | 닫으면 게임 화면 |
| 일시 정지 메뉴 | 메뉴 버튼 목록. 메뉴가 열린 동안 게임이 멈춤 | 저장, 설정, 게임 종료, ESC: 닫기 | 닫으면 게임 화면. 게임 종료는 사망하지 않은 상태이므로 자동 저장 후 종료 |
| 설정 화면 (일시 정지 메뉴에서 열기) | 마우스 감도, 소리 크기 | 마우스 감도 조절, 소리 크기 조절, 뒤로 | 뒤로 가면 일시 정지 메뉴 |
| 마법 줌인 화면 | 마우스 오른쪽 클릭 시 마법으로 줌인되어 화면 확대 (마법별 배율 미정). 그 밖의 표시 정보는 미정 |  |  |
| 시체 확인 표시 (게임 화면 위) | 시체에 가까이 가면 확인 안내, 의뢰 대상이면 의뢰 완료와 받은 의뢰비 표시 | E: 시체 확인 | 게임 화면 유지 |
| 거점 상점 화면 (마법 구매) | 구매할 수 있는 마법, 가격, 보유 돈 | 구매, 닫기 | 닫으면 게임 화면 |
| 회복 지점 (거점에 있는 월드 안의 오브젝트) | 가까이 가면 상호작용 안내, 사용하면 회복 스킬 횟수 초기화 안내 | E: 회복 지점 사용 | 게임 화면 유지 |
| 의뢰 게시판 (거점에 있는 월드 안의 오브젝트) | 나무 게시판에 의뢰서 5장이 붙어 있음 (레퍼런스 이미지 참고). 의뢰서를 바라보고 키를 누르면 그 의뢰서가 줌인되며 의뢰 이름, 설명, 대상 몬스터, 주요 서식 방향 (거점 기준), 의뢰비 표시. 현재 수락한 의뢰 수 (최대 3) | E: 의뢰서 확인, 수락, 줌아웃 | 줌아웃하면 게임 화면 |
| 사망 화면 | 사망 안내 (그 밖의 표시 정보 미정) | 타이틀로 가기, 게임 종료 | 두 버튼 모두 누르는 순간 저장 데이터 삭제. 타이틀로 가기: 시작 화면 (이어가기는 비활성화 상태), 게임 종료: 종료 |

**조작 키**: 모든 상호작용 (시체 확인, 회복 지점, 의뢰서 확인)은 E, 회복 스킬은 G, 탐지와 추적 스킬은 Q, 맵은 M, 의뢰 정보는 J, 일시 정지 메뉴는 ESC, 조준 (마법 줌인)은 마우스 오른쪽 클릭, 마법 발사는 마우스 왼쪽 클릭, 마나 회복 (명상, 누르고 있는 동안)은 R, 달리기는 왼쪽 Shift, 마법 교체는 숫자 키 1\~5 또는 마우스 휠, 이동은 WASD.

**Claude 작업 규칙**

- 이 문서에 없는 기능이나 수치는 임의로 정하지 말고 먼저 질문할 것
- 한 번에 8번 섹션의 한 단계만 작업할 것
- 작업 전에 어떤 씬, 프리팹, 컴포넌트를 만들거나 고치는지 먼저 알려 줄 것. 스크립트의 로직을 바꿔야 할 부분이 보이면 고치기 전에 먼저 알려 줄 것
- 핵심 부분에 짧은 설명을 붙일 것
- 범위를 넓히는 기능은 제안만 하고, "추후 추가"로 기록할 것
