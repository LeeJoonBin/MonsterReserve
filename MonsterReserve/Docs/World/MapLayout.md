# 맵 배치 (Map Layout)

> 온디맨드 문서. 맵 구조물 배치 작업 시 `map-builder`가 읽는다.
> 배치도 이미지: `Docs/World/map-diagram.png`
> 이미지는 위치를 한눈에 보기 위한 것이고, 정확한 칸 좌표는 이 문서의 표를 기준으로 한다.
> 이 배치도는 초안이다. 구역별 몬스터는 미정이다.

---

## 작업 방식

> 결정 : 2026-11-09. 넓은 면적은 규칙 기반으로 채워 토큰과 성능을 아끼고, 눈에 띄는 좁은 곳만 직접 다듬는다.

| 방식 | 쓰는 곳 |
| --- | --- |
| Unity Terrain | 바탕 지면, 높은 지형, 숲과 들판의 나무 (Terrain 나무 기능으로 대량 배치) |
| 에디터 스크립트 | 구역별 테마 에셋 흩뿌리기 (`## 임시값`의 밀도 기준), 길, 서식지 위치 표시 |
| 직접 배치 | 거점 마을, 서식지 8곳의 중심 장식처럼 보기 좋음이 중요한 좁은 곳 |

- 에디터 스크립트는 `map-builder`가 `Assets/Scripts/World/Editor/` 아래에 작성하고, 실행과 스크린샷 확인은 메인 Claude가 Unity MCP로 한다.
- 직접 배치는 오브젝트와 스크린샷마다 토큰이 많이 들므로 위 표의 좁은 곳에만 쓴다.
- 자연스러움, 분위기 같은 최종 다듬기는 사용자가 유니티 에디터에서 한다.

## 좌표 규칙

- 맵은 10 × 10 격자. 열 A~J는 서쪽에서 동쪽, 행 1~10은 북쪽에서 남쪽 방향이다.
- 한 칸 = 500m (임시값). 전체 5km × 5km.
- 위쪽이 북쪽이다. 의뢰서의 서식 방향 (예: 거점 기준 북동)은 이 기준으로 계산한다.
- 거점은 맵 정중앙 (E5, F5, E6, F6 네 칸이 만나는 점)에 있다.
- 방향은 거점 중심에서 서식지 중심을 향한 8방위 (북, 북동, 동, 남동, 남, 남서, 서, 북서)로 나타낸다.

## 섹션

- 맵 전체를 한 씬(Game)에 두고, 작업은 아래 섹션 9개로 나눠 섹션별로 진행한다.

- 섹션 경계는 열 A~C / D~G / H~J, 행 1~3 / 4~7 / 8~10이다. 들판 칸은 그 칸이 속한 섹션에서 작업한다.

## 길

- 거점에서 동서남북 네 방향으로 길이 하나씩 나 있다.
    - 북 : 거점에서 D~G열 3행 (성채 폐허 입구)까지
    - 남 : 거점에서 D~G열 8행 (묘지 입구)까지
    - 서 : 거점에서 C열 (황야 협곡 입구)까지
    - 동 : 거점에서 H열 (늪 입구)까지
- 대각선 방향의 숲 구역으로 가는 길은 없다. 들판을 가로질러 이동한다.

## 높은 지형 (저격하기 좋은 곳)

- 정해진 저격 지점은 없지만, 구역마다 멀리 내려다볼 수 있는 높은 지형을 하나 이상 둔다.
- 위치 : A1, J1, D3, G1, A5, C7, H7, J6, D9, A10, J10

## 임시값

> 모든 값은 임시값이다. 배치 후 사용자가 유니티 에디터에서 보기 좋음, 저격 시야, 성능을 확인하며 조정한다.
> 밀도는 1ha (100m × 100m)당 개수다. 한 칸 (500m × 500m) = 25ha.

| 항목 | 값 (임시값) |
| --- | --- |
| 숲 나무 밀도 | 1ha당 150~200그루 |
| 들판 나무 밀도 | 1ha당 10~20그루 |
| 늪 나무·수풀 밀도 | 1ha당 80~120개 |
| 황야 협곡 바위·선인장 밀도 | 1ha당 5~10개 |
| 서식지 반경 | 100m |
| 길 폭 | 4m |
| 높은 지형 높이 (주변 지면 기준) | 30~50m |
| 거점 마을 실제 크기 | 150m × 150m (E5~F6 네 칸이 만나는 점 중심) |

- 숲 나무 밀도 기준으로 숲 4곳 (36칸, 900ha)에 약 13만~18만 그루가 된다. 성능 문제가 생기면 밀도나 구역 크기 조정을 사용자에게 제안한다. (성능은 미검증)

## 배치할 때 확인할 것

- 에셋 구성 확인 : POLYGON Adventure가 숲과 들판을 채울 만큼 자연 요소를 갖고 있는지, NecroPOLY Lite (Lite 버전)가 묘지 구역 2 × 4칸을 채울 만큼 구성이 충분한지 먼저 확인한다. 부족하면 구역 크기 조정을 사용자에게 제안한다.
- 서로 다른 제작사 에셋 (늪, 묘지)이 Synty 에셋과 어색하게 섞이지 않는지 구역 경계에서 확인하도록 사용자에게 알린다.
- 배치 결과의 보기 좋음과 플레이 감각은 사용자가 유니티 에디터에서 직접 확인한다.
- 에셋 구성 확인 결과 (2026-11-09, 이슈 #1 댓글) 중 섹션 작업 전에 정할 것
    - 남쪽 묘지 : NecroPOLY Lite의 무덤 계열이 15종뿐이라 8칸을 채우면 반복이 눈에 띌 수 있다. 남 섹션 작업 전에 구역 축소 또는 중심부 밀집 + 자연물 채움 중 사용자가 정한다.
    - 동쪽 늪 : Low Poly Swamp Nature에 물 prefab이 없다. 동 섹션 작업 때 수면 처리 방식을 사용자가 정한다.

## 미정

- 구역별 몬스터 (서식지 표의 몬스터 칸)
- 거점과의 거리에 따른 몬스터 난이도 차이를 둘지 여부
- 한 칸 크기 (500m) 확정 여부
- `## 임시값`의 밀도와 크기 확정 여부
