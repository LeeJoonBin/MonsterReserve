# Issue Template

> GitHub 이슈 작성 양식. 각 섹션의 작성 규칙은 `Docs/Documentation/Github Issue Rule.md`를 따른다.

```markdown
## 유형
개발 / 버그수정

## 담당 영역
UI / 맵 / 사운드 / 인스펙터

## 배경 (As-is)
지금 상태와 이 이슈가 필요한 이유

## 목표 (To-be)
이 이슈가 끝났을 때의 상태

## 작업 내용
- [ ] 작업 1
- [ ] 작업 2

## 완료조건 (DoD)
- [ ] 확인할 수 있는 조건 1
- [ ] 확인할 수 있는 조건 2

## 버그 정보 (버그수정일 때만)
- 재현 방법 :
- 실제 동작 :
- 기대 동작 :

## 참고 문서
- Docs/...
```
