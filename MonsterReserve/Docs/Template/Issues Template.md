# Issue Template

> GitHub 이슈 작성 양식. 각 섹션의 작성 규칙은 `Docs/Documentation/Github Issue Rule.md`를 따른다.
> 제목과 라벨은 영어로 쓴다. 본문 언어는 작업 주체에 따라 다르다 (`Github Issue Rule.md`의 "언어"). 한글 본문은 섹션 이름도 한글로 쓴다.

```markdown
## Type
Feature / BugFix

## Area
UI / Map / Sound / Inspector

## Background (As-is)
Current state and why this issue is needed

## Goal (To-be)
State after this issue is done

## Tasks
- [ ] Task 1
- [ ] Task 2

## Definition of Done
- [ ] Verifiable condition 1
- [ ] Verifiable condition 2

## Bug Info (BugFix only)
- Steps to reproduce :
- Actual behavior :
- Expected behavior :

## References
- Docs/...
```
