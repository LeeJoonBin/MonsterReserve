# Pull Request Template

> GitHub PR 작성 양식. `/github-pr` 스킬이 PR을 작성할 때 읽는다.
> 제목 형식은 이슈와 같다 : `[유형][영역] 요약`

```markdown
## 관련 이슈
Closes #이슈번호 (이슈가 없으면 "없음")

## 변경 요약
이번 PR에서 무엇이 바뀌었는지 한두 문장

## 변경 내용
- 생성 : 파일경로(역할)
- 수정 : 파일경로(변경 내용)
- 삭제 : 파일경로(삭제 사유)

## 확인 결과
- [x] 확인 항목 (확인 방법)
- [ ] 미검증 항목 (미검증 사유)

## 사용자 확인 항목
- 유니티 에디터에서 확인한 항목

## 참고
- 관련 문서, 남은 일
```
